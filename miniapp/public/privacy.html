Política de Privacidad

Última actualización: 28 de septiembre de 2026.

1. Qué datos procesa el servicio

Monitor eSports usa la autenticación firmada de Telegram para reconocer al usuario dentro de la Mini App. El servidor valida esa firma y utiliza el identificador de Telegram para decidir el acceso FREE, PRO o a análisis individuales.

Para operar compras y accesos podemos conservar el identificador de Telegram, la aceptación de condiciones, órdenes, recibos y estado de pagos o suscripciones, además de la información mínima necesaria para seguridad, límites de uso y soporte.

2. Para qué se usan

  • Autenticar el acceso a la Mini App y al bot.
  • Mostrar el contenido correspondiente al plan o compra del usuario.
  • Procesar y verificar pagos realizados mediante Telegram Stars.
  • Prevenir abuso, aplicar límites operativos y resolver incidencias de soporte.

3. Servicios utilizados

Telegram proporciona la identidad firmada y procesa los pagos en Stars. Supabase se usa para la API y almacenamiento del servicio, y Vercel aloja la interfaz web de la Mini App. Monitor eSports consulta datos públicos de eSports y logos de equipos a través de fuentes externas como bo3.gg; esas consultas no necesitan enviar tu identificador de Telegram.

4. Contraseñas y datos de pago

Monitor eSports no solicita tu contraseña de Telegram ni almacena números de tarjeta. Las operaciones con Stars se realizan dentro de Telegram y el servicio recibe únicamente la información necesaria para confirmar y administrar el acceso.

5. Conservación

Los registros de compras, consentimientos y acceso pueden conservarse mientras sean necesarios para administrar el servicio, atender soporte, mantener trazabilidad de pagos y cumplir obligaciones aplicables.

6. Contacto

Para consultas sobre privacidad, acceso o compras, escribe a @mitzukyhs.
